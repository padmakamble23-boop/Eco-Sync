# Eco-Sync
Eco-Sync is an autonomous, amphibious robotic system designed for real-time environmental monitoring and waste remediation. 

## Key Features
- **Amphibious Operation:** Capable of navigating both land and water ecosystems.
- **AI-Powered Vision:** Detects and analyzes pollutants using real-time image processing.
- **Live Dashboard:** Monitors site health (AQI, humidity, temperature) and waste density via an interactive map.

## Technologies Used
- **Streamlit:** For the web interface and dashboard.
- **Folium:** For geospatial mapping and site visualization.
- **Python:** Core logic for data handling and AI integration.

## Purpose
Developed for the school science exhibition to demonstrate how autonomous technology can provide actionable insights for a cleaner, sustainable future.
